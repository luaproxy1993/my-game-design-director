# My Game Design Director

Coding-agent skill. When a new scene, opening, character, quest, or playable beat has to be decided, use this author's observed judgments: one primary paradigm, the story window stops before anyone truly leaves, a marked deadly side path sits on the same map, speech sounds like the person already in the scene, and the player can do something with a visible result.

```text
/my-game-design-director
```

Names, places, and event order from the source campaign stay in `references/evidence.md`. They are not a template.

```bash
npx skills add luaproxy1993/my-game-design-director -y
```

Current: **1.0.0**.
